That’s Plinth. It’s open source under the MIT licence. You can use the hosted instance, or run your own copy on your own Cloudflare account; it runs on Workers, R2 and D1. If you use Claude Code, these two commands install the plugin, which brings the server and the skill together, and Codex has its own plugin too. Everything else, including the docs and how to self-host, is at github.com/mr0b0t0/plinth. Thank you, and I’m happy to take questions.

Plinth isn’t only for HTML pages. There are seven kinds of artifact. A page is any HTML, for dashboards, tools and charts. A doc is Markdown that Plinth renders as a finished page, which is what you want for memos and specs. A deck is a slide deck, like this one. A sheet is a real table with typed columns and Excel formulas that Plinth computes. A design lays out artboards at fixed sizes. A whiteboard is a board people edit together, with live cursors. And a design system holds your tokens and components, so agents can reuse your look the next time they make something.

How it works

From agent to link in four steps

01

The agent writes a page

HTML, Markdown or a deck, made in the session.

02

It publishes over MCP

One publish_artifact call, from Claude, Codex or any MCP client.

03

Plinth keeps version 1

Private by default, at a link that stays the same.

04

You share the link

With people you invite by email, or anyone with the link.

Every later change is a new version at that same link.

Here’s what a publish looks like, one click at a time. It starts in the agent’s session: it writes a page, a Markdown doc or a deck. [click] Then it makes one call over MCP, publish_artifact. That works the same from Claude, from Codex or from any other MCP client. [click] Plinth stores that as version one. It’s private by default, and the link it gets never changes. [click] And then you share it: with specific people you invite by email, or with anyone who has the link. From then on, every change, whether a person or an agent makes it, is a new version at that same link.

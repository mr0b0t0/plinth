By design

Three numbers that stay fixed

7

artifact types, from a page to a design system

0

lines of server code per artifact: static HTML and assets only

1

link for every version, from the first to the latest

Three numbers describe how Plinth is built. Seven: the kinds of artifact it understands, from a plain page all the way to a design system. Zero: the lines of server code any artifact gets. An artifact is static HTML plus its files. The only server behaviour a page can reach is Plinth’s own fixed services, like shared data, and only if the page opts in. That’s a big part of why it’s safe to host pages written by strangers. And one: one link per artifact, for every version. Send it once, and it always shows the latest.

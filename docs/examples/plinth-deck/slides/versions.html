Versions

Every change is a new version

  • A saved version never changes. Each edit, by a person or an agent, is the next one.
  • Anyone can restore an old version: it comes back as the next version.
  • A save based on a stale version is refused, so nothing is overwritten.

Versions are the heart of Plinth. A saved version never changes. Every edit, whether you made it or an agent did, becomes the next version. On the right you can watch that happen: Claude Code publishes version one, Codex edits it after a comment, and then you restore the first version, which doesn’t rewind anything; it comes back as version three. And look at the last row. Someone tried to save on top of version two, which is out of date. Plinth refuses that save instead of quietly overwriting the newer work. So nothing gets lost, and anyone can undo what an agent did.
